# House Price Prediction

A machine learning project that predicts house prices based on features like area, number of bedrooms, location and more.

## Overview
The goal is to build a regression model that estimates the selling price of a house. The project covers data cleaning, exploratory data analysis, feature engineering, model training and evaluation.

## Dataset
- Source: [HousePricePrediction.csv]
- Size: 2919 x 13


## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Lab

## Workflow
1. Data cleaning: handled missing values and outliers
2. EDA: analysed price trends and feature correlations
3. Feature engineering: encoded categorical columns, scaled numeric features
4. Model building: Linear Regression, Random Forest
5. Evaluation: R2 score, RMSE, MAE

## Results
R2 Score: 0.374142179613853
MAE: 30829.93666432187
RMSE: 41138.55870230106

- Best model: Random Forest
- Key insight: area and location have the strongest impact on price
